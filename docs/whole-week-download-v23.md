# v23 — 이번 주 악보 전체 다운로드

- 이번 주의 팀 공개 예배 도구에 `악보 전체 다운로드` 버튼을 추가했다.
- 클릭 시 해당 공개 버전을 복제해 다운로드 목록을 고정한다. 준비 중 새 버전이
  공개되어도 버전이 섞이지 않는다. 수정 초안이나 개인 메모를 포함하지 않는다.
- 이미 생성된 공개 악보 이미지를 그대로 묶는다. 송폼·구간 표시와 원본 화질을 유지한다.
- 파일 이름은 `01_곡제목_p01.png` 형태이며, 곡·페이지 순서와 중복 제목을 구분한다.
- `fflate`의 저장 방식 ZIP을 사용한다. PNG/JPEG를 다시 압축하거나 렌더링하지 않는다.
- 준비 완료 후 새 클릭으로 ZIP 다운로드 또는 지원 기기의 다중 이미지 공유를 실행한다.
- 진행률, 취소, 실패 후 재시도를 제공한다. 한 페이지라도 실패하면 부분 ZIP을 제공하지 않는다.
- 각 파일은 기존 교회별 파일 접근 API에서 읽는다. 교회 전환/창 종료 시 요청을 취소한다.
- 모바일 메모리를 위해 순차적으로 읽고 전체 이미지 합계 80 MiB를 초과하면
  개별 곡 저장을 안내한다. 중복 파일은 한 번만 요청한다. 다운로드 모듈은 필요할 때 로드한다.

검증: TypeScript, 프로덕션 빌드, 전체 곡·복수 페이지·한글 이름·순서·바이트 동일성,
미공개 초안 제외, 누락·실패·취소·용량 제한·로그인 만료·오프라인·시간 초과 검사.
다른 ZIP 구현인 Python zipfile로 모든 파일과 CRC/UTF-8 이름을 재검사했다.
실제 iPhone/Android의 시스템 저장·공유 화면은 이 환경에서 직접 검증하지 못했다.
