# v28 — 교회별 예배 콘티 알림

## 동작
- 예배를 처음 `팀에 공개`할 때 알림 이벤트, 현재 활성 팀원들의 알림함, 허용된 기기의 전송 대기를 공개 트랜잭션 안에 함께 기록한다.
- 기존 팀원도 재가입할 필요 없이 다음 공개부터 알림함에 소식이 쌓인다. 기기 푸시는 `콘티 알림 켜기`를 직접 누르고 브라우저에서 허용해야 한다.
- 초안 저장, 실패/충돌한 공개, 재공개, 팀원의 송폼 수정, 휴지통 복구는 새 공개 알림을 만들지 않는다. 과거 예배 알림을 일괄 소급 전송하지 않는다.
- 상단 종, 이번 주 안내, 내 정보 설정에서 알림함을 연다. 기기·교회별 켜기/끄기, 읽음 처리, 테스트 알림(1분 제한)을 제공한다.
- 아이폰/아이패드는 iOS/iPadOS 16.4 이상에서 Safari로 홈 화면에 추가한 웹 앱을 열어 허용한다. 앱 안에 설치 및 차단 해제 안내가 있다.
- 알림을 누르면 서버가 현재 소속과 읽기 권한을 다시 검증한 뒤 해당 예배로 이동한다. 로그인 복귀 경로에 알림을 유지한다. 이미 열린 악보 편집창은 다시 로드하지 않고, 작업을 닫을 때까지 이동을 보류한다.

## 저장 및 보안
- 0006은 새 알림 테이블만 추가하며 기존 예배·회원 데이터는 바꾸지 않는다. 교회/예배 영구 삭제 시 관련 알림이 외래 키로 함께 삭제된다.
- 읽음 기록은 본인만 변경한다. 비활성 계정, 탈퇴/중지된 교회, 삭제된 예배는 읽기 및 전송 대상에서 제외한다.
- 기기 endpoint는 한 계정에만 연결한다. 다른 계정이 명시적으로 켜면 기존 연결을 제거한다. 로그아웃은 기존 top-level 링크를 유지하면서 현재 기기 연결 해제 요청을 keepalive로 시작한다.
- 서버 전용 VAPID private JWK는 Sites secret이다. public key만 인증된 클라이언트에 반환한다. 키를 배포마다 재생성하지 않는다.
- RFC 8291 aes128gcm 및 RFC 8292 VAPID를 Worker Web Crypto로 처리한다. 공식 푸시 서비스의 HTTPS endpoint만 허용하고 리디렉션은 따라가지 않는다. 개인 악보 메모는 푸시 본문에 포함하지 않는다.
- 서비스 워커는 알림 전용이며 페이지·로그인·개인 악보를 캐시하지 않는다.

## 전달 범위와 재시도
- 공개 응답은 전송 완료를 기다리지 않으며, 20초 작업 예산의 `waitUntil`에서 12개씩 처리한다. 전송 대기와 처리 lease를 D1에 저장한다.
- 404/410은 만료 기기를 지우고, 네트워크 오류/429/5xx는 최대 5회 지수 지연 및 Retry-After에 따라 재시도한다. 24시간 지난 이벤트, 이미 읽은 이벤트, 권한이 사라진 대상은 취소한다.
- 재시도 작업은 다음 공개 또는 활성 앱의 알림함 조회(45초 및 복귀 시)에 재개된다. 별도 cron/queue는 없다. 장시간 서버 요청이 없으면 재시도 시점은 보장하지 않는다. 첫 전송이 성공하면 푸시 서비스가 TTL 24시간 동안 전달을 담당한다.
- OS 집중 모드·절전·차단·네트워크에 따라 실제 표시 시점은 달라진다. 앱 알림함은 기기 허용 여부와 독립적으로 보관한다.

## 검증
- RFC 8291 공개 테스트 벡터와 암호문 일치, VAPID 서명 검증, 잘못된 키/주소 거부.
- 실제 Worker 런타임에서 암호화 및 outbound 요청 검증. Worker에서 지원하지 않는 redirect:error를 manual로 수정하고 비추적 동작 확인.
- 57개 알림 API 응답 검사 및 상태 단언: 동시 공개/중복, 기존 회원, 기기별 설정, 암호화 페이로드 복호화, 교회 격리, 탈퇴, 타인 읽음/해제 금지, 재시도, 만료 정리, 계정 전환, 삭제 cascade.
- 서비스 워커 이벤트 테스트: 표시, 잘못된 payload, 안전한 링크, 기존 편집창 유지, 인증 자료 비캐시.
- UI 로직/SSR 검사: 직접 탭에서만 동의 요청, 기존 회원 안내, 끄기 유지, iOS 설치, 차단 안내, 읽지 않음 접근성. Safari/Chrome 대상 CSS 컴파일.
- 기존 교회 격리 108개, 운영/승인/삭제 118개, 송폼 권한 57개 검사와 개인 악보 분리·초안 복구·모바일 이동·로그인 경로 회귀 검사 통과.
- 타입 검사 및 프로덕션 빌드 통과. 실제 iPhone/Android/데스크톱 브라우저의 설치·팝업·화면 배치는 이 환경에서 실행하지 못했다. 실제 기기의 `테스트 알림`으로 확인할 수 있다.
